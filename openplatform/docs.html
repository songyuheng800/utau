API 文档

标准 OAuth 2.0 授权码流程 + 资源 API。所有请求基于 HTTPS。

接口地址 授权流程 授权端点 Token 端点 用户信息 文件 API 刷新令牌 错误说明

接口地址

API 基地址（Cloudflare Pages Functions）：

https://utau-4oo.pages.dev/api/openplatform

授权页（前端页面）：https://songyuheng800.github.io/utau/openplatform/authorize.html

授权流程（Authorization Code）

1. 应用跳转授权页 https://songyuheng800.github.io/utau/openplatform/authorize.html ?client_id=<你的client_id> &redirect_uri=<注册时的回调地址> &scope=read%20write &state=<任意随机串，防CSRF> 2. 站长在授权页输入管理站 Token 并确认 → 浏览器 302 跳回你的回调地址： <redirect_uri>?code=<一次性授权码>&state=<原样返回> 3. 应用用授权码换令牌（POST /oauth/token）： → access_token（1 小时）+ refresh_token（30 天） 4. 携带 Bearer access_token 调用资源 API

授权端点

预检（授权页自动调用，无需手动）

GET /oauth/authorize?client_id&redirect_uri&scope

校验应用是否有效、回调地址是否匹配、权限是否已注册。

确认授权

POST /oauth/authorize

{ "client_id": "…", "redirect_uri": "https://你的应用.com/oauth/callback", "scope": "read write", "state": "abc123", "token": "管理站Token" } → 200 { "ok": true, "redirect_url": "…?code=xxx&state=abc123" }

Token 端点

POST /oauth/token —— 授权码换令牌

{ "grant_type": "authorization_code", "client_id": "…", "client_secret": "…", "code": "上一步拿到的code", "redirect_uri": "https://你的应用.com/oauth/callback" } → 200 { "access_token": "…", "token_type": "Bearer", "expires_in": 3600, "refresh_token": "…", "scope": "read write" }

用户信息

GET /api/userinfo

Authorization: Bearer <access_token> → 200 { "ok": true, "user": { "id": "admin", "name": "UTAU管理员" }, "scope": "read write" }

文件 API

文件列表（公开只读）

GET /api/files

→ 200 { "ok": true, "count": 12, "files": [ { "name": "…", "size": 12345, "raw": "https://…" } ] }

上传文件（需 write）

POST /api/files

Authorization: Bearer <access_token> { "filename": "工程名.ustx", "data": "<base64 编码的文件内容>" } → 200 { "ok": true, "filename": "2026-…_工程名.ustx" }

支持扩展名：ust / ustx / vsq / vsqx / vpr / pp2 / pp3 / zip / rar，单文件上限 50MB（base64）。文件名会自动加时间戳前缀，同名不会覆盖。

删除文件（需 write）

DELETE /api/files

Authorization: Bearer <access_token> { "filename": "2026-…_工程名.ustx" } → 200 { "ok": true }

刷新令牌

POST /oauth/token —— 刷新（refresh_token 每次轮换）

{ "grant_type": "refresh_token", "client_id": "…", "client_secret": "…", "refresh_token": "…" } → 200 新的 access_token + refresh_token

错误说明

HTTP场景
400参数错误 / 应用不存在 / 回调地址不匹配 / 授权码无效或已使用
401access_token 缺失、无效或过期
403client_secret 错误 / 应用已吊销 / 管理站 Token 无效 / 无 write 权限
404应用不存在 / 文件不存在
500服务端错误（多为 KV 未绑定或 GitHub 写入失败）
