代码示例

几行代码完成 API 调用

// 1. 用授权码换取 access_token
POST https://utau-4oo.pages.dev/oauth/token
  grant_type=authorization_code
  &code=AUTH_CODE
  &client_id=YOUR_CLIENT_ID
  &client_secret=YOUR_CLIENT_SECRET

// 2. 调用用户信息接口
GET https://utau-4oo.pages.dev/api/userinfo
  Authorization: Bearer ACCESS_TOKEN

// 返回示例
{
  "openid": "user_abc123",
  "name": "用户名",
  "avatar": "https://..."
}
